# Receipts 🧾\nPrivate-first receipts + expense tracker that stores everything locally (no account, no cloud, no drama).  \nScan receipts, attach photos, **save screenshots and videos**, tag expenses, and export when you need to prove you’re not making numbers up.\n\n## ✨ Features\n- **Local-only storage** (offline by default)\n- Add receipts with:\n  - Photo capture\n  - Image upload\n  - **Screenshots**\n  - **Videos**\n- OCR-ready structure (optional, depending on implementation)\n- Smart fields:\n  - Merchant\n  - Amount\n  - Date\n  - Category\n  - Notes\n  - Tags\n- Search + filter (merchant, category, date range, amount range)\n- Monthly totals + simple insights\n- Export:\n  - CSV (expenses)\n  - ZIP (media + CSV) (optional)\n- No login. No tracking. No “we value your privacy” lies.\n\n## 🧱 Tech Stack (suggested)\n- **React Native (Expo)**\n- **SQLite** for local database\n- **expo-image-picker** for photos\n- **expo-file-system** for storage\n- **expo-media-library** (optional, for saving to device gallery)\n- **expo-av** (video playback)\n- **expo-sharing** (export/share)\n\n## 📦 Project Setup\n### 1) Install dependencies\n```bash\nnpm install\n```\n\n### 2) Start development server\nFor development, use Expo CLI to run the app:\n```bash\nnpx expo start\n```\n\nOpen the Expo Go app on your device and scan the QR code, or run the app directly on an emulator (iOS Simulator or Android Emulator).\n\n### 3) Build APK/IPA for Production\nUse Expo's build service to create a standalone application:\n```bash\neas build --profile production --platform <android|ios>\n```\n\n## 🖥️ Contribution Guide\nAll contributions are welcome!
